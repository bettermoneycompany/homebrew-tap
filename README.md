# bettermoneycompany/homebrew-tap

Homebrew tap for Better Money Company internal Mac tools.

## Usage

```sh
brew tap bettermoneycompany/tap
brew install --cask <tool-name>
```

Or in one command:

```sh
brew install --cask bettermoneycompany/tap/<tool-name>
```

## Available casks

| Cask | Description |
|------|-------------|
| [`browser-switcher`](Casks/browser-switcher.rb) | Menu bar app that switches the default browser between Chrome and Firefox on a weekday schedule. Source: [cjustice/browser-switcher](https://github.com/cjustice/browser-switcher). |
